**문제** · 스마트스토어·쿠팡 셀러는 매출은 바로 보이지만, 수수료·택배비·광고비·원가를 뺀 진짜 남은 돈은 엑셀로 직접 맞춰 봐야 압니다. 마켓마다 정산 파일이 달라서 정산이 빠져도 모르고 지나가고, 공급처 발주서와 부가세 자료도 매번 따로 만듭니다.

**타깃과 포지셔닝** · 스마트스토어·쿠팡·테무 등 여러 마켓에서 혼자 파는 소규모·위탁 셀러. 첫 약속은 **"매출 말고 진짜 남은 돈"** 하나로 잡고, 그 뒤에 발주·정산·세금 일을 붙였습니다.

**피벗 (2026.10)**

> 처음 기획은 경쟁사 가격·리뷰 모니터링이었습니다. 가격 수집에 쓰려던 공식 API가 종료되고 자동 수집은 약관으로 막혀 있어 핵심 기능을 오래 유지할 수 없다고 판단했습니다. 셀러 커뮤니티에서 반복해서 나오는 고민(정산·현금흐름·순이익)을 근거로 방향을 바꿨습니다.

**핵심 의사결정**

1. **가입 전에 가치 확인** · 유입에 비해 가입이 적다는 퍼널 데이터를 보고, 가입 없이 예시 가게 장부로 모든 기능을 써 보는 둘러보기를 추가. 내 파일을 올리는 순간에 가입하도록 설계하고 구글 계정 가입도 지원
2. **신뢰 장벽 낮추기** · 마켓 비밀번호나 API 키를 받지 않고 엑셀 업로드만으로 동작. 고객 이름·연락처·주소는 브라우저에서 걸러 서버에 저장하지 않음
3. **데이터로 콘텐츠 운영** · 공식 검색 트렌드 API로 셀러 검색어를 조사해 블로그 주제를 정하고(30여 편 발행), 글마다 꼬리표 링크를 달아 방문과 가입을 추적
4. **수익 모델** · 무료 + 3단계 구독(월 7,900 · 29,900 · 99,000원). 마켓 수, 기록 기간, 발주·결산 기능으로 구분. 2026년 12월까지 전 기능 무료 베타

**현재와 다음**

- 오픈 베타 운영 중(2026년 11월~). 실제 셀러 파일로 양식 인식을 넓히는 단계
- 추적 중인 퍼널: 글별 유입 → 둘러보기 → 가입 → 첫 파일 업로드 → 유료 전환
- 다음 계획: 쿠팡 주문·정산 자동 불러오기, 유료 전환 후 전환율·이탈률 공개

**질문** · 운동 앱 '플랜핏'이 미국 시장에 진출한다고 가정할 때, 사용자가 운동을 꾸준히 이어가게 하려면 무엇이 필요할까

**가설** · 같은 시간에 함께하지 않아도 서로의 운동을 느끼게 하는 비동기 소셜 장치가 지속률을 높일 것

**실행**

- '고스트 싱크(Ghost Sync)', '달성률 동기화' 등 사용자 반응 기반 비동기 소셜 기능 기획, 5주간 기획 아티클 연재
